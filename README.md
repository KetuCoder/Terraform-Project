# Deploy Strapi CMS on AWS EC2 Using Terraform (Ubuntu)

This Terraform project deploys a fully automated **Strapi CMS** running on **Ubuntu 22.04** on AWS EC2.

## 📌 Features
- Ubuntu 22.04 LTS
- Node.js 18 LTS
- Strapi installed automatically with user-data script
- PM2 process manager for auto-restart
- Open port 1337 for Strapi
- SSH access
